Pieges :
  - le SDIRK en mode rapide (solver.matrix_free = true : Pardiso sans
    raffinement iteratif) echoue pour certains pas (NaN a dt = 0.04,
    erreur 7e-3 a dt = 2.5e-3 sur le maillage 16x16 raffine) : les
    references SDIRK utilisent solver.matrix_free = false ;
  - le pas de temps du LI ne doit pas depasser la limite CFL de sa
    partie explicite (7.3e-3 en 6.5) ;
  - avec -ffast-math (defaut de diskpp), std::isfinite peut etre
    supprime : les etudes cfl testent la finitude sur les bits ;
  - un executable compile avant le 15 octobre ignore les options de
    6.7 (avertissement "unknown parameter problem.ricker.shape") et
    calcule un autre probleme : verifier l'en-tete de log.txt.
